Tygron QGIS Plugin

A QGIS integration for the Tygron Platform, allowing users to stream environmental data layers and perform live edits on project geometries via WFS-T.

Installing the plugin:
1. Download the ZIP File containing the source code
2. Extract the ZIP contents as a folder in the following location:
    C:\Users\[user]\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins

Opening a project:

When the plugin is installed, you may obtain a Tygron Platform Session API Key to interact with a project through QGIS.

Step 1: open or create a project.
Step 2: When you are inside the editor, navigate to "Tools" tab at the top of the window.
Step 3: Click on API Overview, you will be redirected to a browser window.
Step 4: Copy the API Session Key in bold text.
Step 5: Paste the key in the plugin window.
